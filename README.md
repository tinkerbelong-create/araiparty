araiが作ったボードゲームで遊べるポータルサイト。

- `/` … 遊び場トップ(ゲーム選択)
- `/mystery/` … **マーダーミステリー**(3人用。シナリオJSON差し替え式。第1弾『ケーキを食べた能力者』)
- `/shuzomas/` … **シュゾマス**(2〜8人のオンライン推理ゲーム)
- `/jandekken/` … **ジャンデッキケン**(デッキ構築×じゃんけん。🤖AI作。ソロvsCPU / 招待コードで1対1オンライン対戦・CPU参加/切断時CPU代行あり)
- `/countfruits/` … **カウントフルーツ**(フルーツを数える1対1の作問バトル。CPU対戦OK)
- `/dorobou/` … **ドロボウ市場**(2〜4人の同時出し値札バトル。🤖AI作オリジナル。CPU対戦OK)
- `/bombsort/` … **ボムわけ!**(1人用スコアアタック。爆弾を赤黒に仕分けるアクション)

- `/monoku/` … **モンオク!**(モンスターを競り落としてコンボ編成バトル。2〜4人。CPU対戦OK)

## マーダーミステリー 🍰🕯

通話(Discord・LINEなど)をつなぎながら遊ぶマーダーミステリー。**マダミスが初めての人でも遊べる**ように、画面が進行役をやってくれます。**GM(進行役)は不要**。

**第1弾『ケーキを食べた能力者』(3人用・約45分・araiオリジナル)**
ヒーロー大学の学生寮。入学祝いのケーキがひと切れだけ消えた。この家にいるのは、自分の力を隠してきた3人の能力者——。

- **必ず一度止まります。** 「つぎは〈第1回 話し合い〉です。○○してください」という案内が出て、**全員が「完了」を押すまで進みません**。今どのステップか(3 / 8)も常に表示されます
- **キャラクターはランダム配布。** 招待コードで3人そろえて開始するだけ
- **ハンドアウトは本人にしか届きません。** 他人のシートも真相も、サーバーから送られません
- **やることは「能力を使うか、使わないか」だけ。**(紙の原作と同じ)能力は1人2回まで。使うと「誰が使ったか」だけが全員に伝わり、**何を使ったかは伝わりません**
- 最後は選択式で回答 → **自動採点**。「自分の能力がバレていない」判定も他の2人の回答から自動で行われます
- エンディングでは管理人が空間の記憶を語り、総合1位が発表されます

### シナリオを追加する

`scenarios/<id>.json` を1つ置くだけで一覧に出ます(**public には置かないこと**。秘匿情報が漏れます)。
スキーマは `マダミス_仕様書.md` と `scenarios/cake.json` を参照。ロジックは `mm_core.js`(進行・能力解決・採点)、通信は `mm_server.js`、画面は `public/mystery/index.html`。

テストは `node test_mm.js`(68項目。秘匿情報の漏れ・ステップ進行・能力解決・採点)。

## シュゾマス 🍺

「お酒の採点会」がテーマの2〜8人用推理ボードゲーム『シュゾマス』のオンライン対戦版です。

24種の食材(度数は毎回ランダム・全員に非公開)から3つ選び、合計が**ちょうど3.0%**のお酒を最初に造ったプレイヤーの勝ち。毎ラウンド全員が同時にお酒を公開し、見えるのは**順位だけ**。順位・賞金・評価の動きを手がかりに、正解の組み合わせを推理しましょう。

- 友達と**招待コード**で集まって対戦(アカウント不要・名前だけ)
- 足りない席は**CPU**で埋められる/対戦中に切断してもCPUが自動代行
- 度数などの秘匿情報はすべてサーバー管理(server-authoritative)。クライアントには一切送信されません
- 手書きの計算スペース、BGM付き

*大学祭で展示した対面ボードゲームのデジタル化作品です。*

## 遊び方

1. ホストが「部屋を作る」→ 5文字の招待コードを友達に共有
2. 友達は名前とコードで「参加する」(2〜8人、足りなければホストがCPU追加)
3. 人数がそろったらホストが「開店する!」(2〜8人)
4. マイ食材を選び(自分だけ度数が見える)、毎ラウンド食材3つでお酒を仕込む
5. ちょうど3.0%を最初に造った人が優勝!(3.1%以上は失敗、評価0で情報公開…詳しいルールはゲーム内「📜 ルールを読む」へ)

## カウントフルーツ 🍓🍒🍋🍌

降ってくる4種のフルーツ(イチゴ・チェリー・レモン・バナナ)を数えて、**落下が終わってから公開される問題**に答える1対1のゲーム。何を聞かれるかわからないので、全部数えておくしかない!

このゲームの核は**プレイヤーが作問すること**。出題者は「どの問題を出すか」と「どのフルーツを何個降らせるか」を決めて、相手が数え間違えそうな状況を作ります。

- 最初に**15問**が両プレイヤーに公開され、各自こっそり**3問**選ぶ(選択は相手に非公開)
- 先攻後攻はランダム。3回戦、毎回戦交互に出題
- 各プレイヤーはフルーツを**75個**(ロビーで15〜300個に変更可)持ち、3回の出題に配分して使う(例: 1回目に30個使うと残り2回で45個)
- 得点: 正解(ピッタリ/択あて)で**+10pt** / 入力式のずれは1につき−1(0未満なし) / 選択式のハズレはペナルティ(2択−10 / 3択−7 / 4択−5)。合計点で勝負
- 後の出題用にフルーツを最低1個ずつ残す必要あり。「偶数?奇数?」の問題は対象フルーツ1個以上が必須
- CPU対戦・対戦中切断時のCPU代行あり。正解と採点はサーバー管理

## ドロボウ市場 🦹💰(AI作)

売れているショートゲームの定石(同時出し・バッティング無効・使い切りリソース・セットコレクション)をもとに**AIが設計したオリジナルゲーム**。2〜4人、10ラウンド、約8分。

- 毎ラウンド人数分の品物(コイン/宝石/ドロボウ)が市場に並び、全員が値札1〜5から1枚を**同時出し**
- 高い値札の人から順に、残っている品物から**好きなものを自分で選んで**取る。**同じ数字はケンカ**で何も取れない(品物は流れる)
- ドロボウ(−3〜−5点)は最後まで残るので安い値札の人に押し付けられがち → **わざとケンカを狙って回避**する読み合いが核
- 値札は使い切り(5ラウンドで一巡×2周)。全員の残り値札は公開情報
- 宝石は1個2点+3色セットで+7点。10ラウンドの合計点勝負(同点は宝石数→ドロボウの少なさ)
- CPU対戦・切断時のCPU代行あり

## ボムわけ! 💣✏️(1人用・araiオリジナル)

上から降ってくる爆弾を、**線でころがして**左右の釜に仕分けるお絵かきアクション。

- **左クリック長押し**で線を描く。描いている間だけ**実体化**して爆弾を受け止める
- そのまま離すと線は**消える**。離す前に**右クリック**するとその場に**固定**(最大3本)
- 固定した線は(描いていないときに)右クリックで消せる。スマホは📌固定/🧹全消しボタン
- **爆弾は画面に10秒いると自爆**してライフ−1(残り3秒で赤点滅+カウントダウン)
- くろい爆弾は左の釜、あかい爆弾は右の釜へ。**下に落とす/違う釜もライフ−1**(初期ライフ5)
- ✨金の爆弾を釜に入れると**+5点&ライフ+1**。出現はどんどん速くなる。ハイスコアはブラウザに保存

*サーバー処理なしの完全クライアントゲーム(canvas物理)。オリジナルキャラ・オリジナル実装です。*

## クアドルカラー 🟥🟦🟨🟩(1〜10人)

4色の正方形が敷き詰められた共通盤面から、手持ちの**2×2色パターンピース**がピッタリはまる「4マスの境目(交点)」を探して早はめするリアルタイムレース。ボードゲーム『クアドルカラー』のデジタル化。

- 盤面は**6×6(36マス) / 8×8(64マス)**、手持ちは**3〜5枚**、制限時間は**3〜5分**からホストが選べる
- **回転あり**(どの向きではめてもOK。ピースは↻で回して見比べられる)
- お手つき(はまらない場所を指定)は**2秒操作ロック**
- 全部はめたら「抜け」。**抜けた順位とタイムが全員に通知**される
- **抜けた人はほかの人の手札が見える**観戦モードに(声援・実況OK)
- 最後の1人が終わるか時間切れで終了。未完の人は残り枚数順(同数はお手つき少ない順)
- 最大10人。CPU参加・切断時のCPU代行あり。手札はサーバー管理で本人にのみ配信

## モンオク! 🐾💰(2〜4人)

オークション×アイテム×トーナメントのモンスターバトル。各自**コイン60+初期モンスター2体(非公開!)**を持ち、共有15体を1体ずつ**同時入札**で競る。**所持数は無制限**(最低3体だけは終盤の優先購入タイムで保証)。競りのあとは**個人アイテムショップ**、最後は**手動トーナメント**で決着。

- オリジナルモンスター24種に**レア度**(SR=強い/R=ふつう/N=弱い)。弱いNは「えんぐん(同タイプ支援)」「ぎせい(散り際バフ)」などの**コンボパーツ**——N2体でSRを怪物にする編成が狙い目
- タイプ相性は火>草>雷>水>火(有利1.5倍/不利0.75倍)。**相性表とコンボ早見表を画面右下に常時表示**
- **アイテム7種**(4〜28コイン、強いほど高い・各1個): やくそう/おまもり/スパイス/パワーリスト/ブースター/メガホン/でんせつのメダル
- トーナメントは**毎試合、全所持から3体+出撃順を選び直せる**。自分の試合以外は観戦なしの待機(結果だけ通知)
- バトルは**対話型**: 毎ターン両者が同時に「⚔こうげき/🔄こうたい」を選択(交代は攻撃より先に発動・そのターン攻撃不可)。倒れたら**次に出すモンスターも自分で選ぶ**。行動25秒/送り出し15秒(時間切れは自動)
- 順位は優勝>準優勝>ベスト4、同順位は残りコイン。CPU対戦・切断時CPU代行あり

## BGM 🎵

ホームと全ゲームにBGMつき(`public/bgm.js`)。音源ファイルなしでWebAudioがループ演奏する軽量方式で、ゲームごとに曲調が違う(ホーム=ゆったり、アクション=疾走、パズル=集中、泥棒=スウィング等)。🔊ボタンでON/OFF、音量はスライダーで調整でき、設定は全ゲーム共通でブラウザに記憶される。シュゾマスのみ従来のmp3 BGM。

## ローカルで動かす

Node.js 18以上が必要です。

```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` を開くと遊べます。同じWi-Fi内なら「あなたのPCのIP:3000」で友達も参加できます。

## Render(無料枠)で公開する

1. このリポジトリをGitHubへプッシュ
2. [render.com](https://render.com/) → **New → Web Service** → リポジトリを選択
3. 設定を確認: Runtime **Node** / Build Command `npm install` / Start Command `npm start` / Instance Type **Free**
4. 発行された `https://〇〇.onrender.com` を友達に共有

> 無料枠は15分間アクセスがないとスリープし、次のアクセス時の起動に30秒〜1分かかります。サーバー再起動で進行中の部屋は消えます(部屋は24時間で自動掃除)。

### 通信プロトコル(改造したい人向け)

クライアント→サーバー: `createRoom / joinRoom / addCpu / removeCpu / startGame / chooseMy / submit / backToLobby`
サーバー→クライアント: `state`(公開情報+本人限定情報) / `reveal`(ラウンド結果)

コアロジックは853件のユニットテストと1000ゲームの自動対戦シミュレーションで検証済みです。
