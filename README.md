## シュゾマス 🍺

「お酒の採点会」がテーマの2〜8人用推理ボードゲーム『シュゾマス』のオンライン対戦版です。

24種の食材(度数は毎回ランダム・全員に非公開)から3つ選び、合計が**ちょうど3.0%**のお酒を最初に造ったプレイヤーの勝ち。毎ラウンド全員が同時にお酒を公開し、見えるのは**順位だけ**。順位・賞金・評価の動きを手がかりに、正解の組み合わせを推理しましょう。

- 友達と**招待コード**で集まって対戦(アカウント不要・名前だけ)
- 足りない席は**CPU**で埋められる/対戦中に切断してもCPUが自動代行
- 度数などの秘匿情報はすべてサーバー管理(server-authoritative)。クライアントには一切送信されません
- 手書きの計算スペース、BGM付き

*大学祭で展示した対面ボードゲームのデジタル化作品です。*

## 遊び方

1. ホストが「部屋を作る」→ 5文字の招待コードを友達に共有
2. 友達は名前とコードで「参加する」(2〜8人、足りなければホストがCPU追加)
3. 人数がそろったらホストが「開店する!」(2〜8人)
4. マイ食材を選び(自分だけ度数が見える)、毎ラウンド食材3つでお酒を仕込む
5. ちょうど3.0%を最初に造った人が優勝!(3.1%以上は失敗、評価0で情報公開…詳しいルールはゲーム内「📜 ルールを読む」へ)

## ローカルで動かす

Node.js 18以上が必要です。

```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` を開くと遊べます。同じWi-Fi内なら「あなたのPCのIP:3000」で友達も参加できます。

## Render(無料枠)で公開する

1. このリポジトリをGitHubへプッシュ
2. [render.com](https://render.com/) → **New → Web Service** → リポジトリを選択
3. 設定を確認: Runtime **Node** / Build Command `npm install` / Start Command `npm start` / Instance Type **Free**
4. 発行された `https://〇〇.onrender.com` を友達に共有

> 無料枠は15分間アクセスがないとスリープし、次のアクセス時の起動に30秒〜1分かかります。サーバー再起動で進行中の部屋は消えます(部屋は24時間で自動掃除)。

## 構成

```
├─ server.js          … ゲームサーバー (Node.js + Express + Socket.IO)
├─ shuzomas_core.js   … シュゾマスのゲームロジック
├─ jd_server.js       … ジャンデッキケン対戦サーバー(1対1)
├─ janken_core.js     … ジャンデッキケンのゲームロジック
├─ package.json
└─ public/                  … クライアント(ブラウザ配信)
    ├─ index.html            … あらいの遊び場(ポータル)
    ├─ shuzomas/             … シュゾマス(クライアント+BGM+食材画像)
    └─ jandekken/            … ジャンデッキケン(ソロ版・単一HTML)
```

### 通信プロトコル(改造したい人向け)

クライアント→サーバー: `createRoom / joinRoom / addCpu / removeCpu / startGame / chooseMy / submit / backToLobby`
サーバー→クライアント: `state`(公開情報+本人限定情報) / `reveal`(ラウンド結果)

コアロジックは853件のユニットテストと1000ゲームの自動対戦シミュレーションで検証済みです。
